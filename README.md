# 🌙 지유의 별빛 정원

> 세상에 딱 하나, **홍지유**만을 위해 만들어진 앱.

틱이 살짝 있는 지유가 핸드폰을 만질 때, 자극적인 영상이나 경쟁하는 게임 대신
**여유롭고, 즐겁고, 화려한** 놀이를 할 수 있도록 만든 선물용 웹앱입니다.
곧 외국으로 떠나는 지유가 인터넷 없이도, 어느 나라에서도 열어서
선물한 사람을 떠올릴 수 있도록 설계했습니다.

---

## 💡 왜 이렇게 만들었나 (구상)

틱은 긴장·불안·피로할 때 심해지고, 편안하고 몰입해 있을 때 잦아드는 경향이 있습니다.
그래서 이 앱은 보통 게임의 문법을 전부 뒤집었습니다.

| 보통 게임 | 지유의 별빛 정원 |
|---|---|
| 점수, 랭킹, 경쟁 | **없음** — 이기고 지는 것 자체가 없음 |
| 시간제한, 재촉 | **없음** — 모든 것이 지유의 속도로 |
| 실패, 게임오버 | **없음** — 무엇을 해도 예쁜 결과만 나옴 |
| 빠른 점멸, 강한 자극 | 느리게 반짝이는 별, 부드러운 파스텔 빛 |
| 광고, 인터넷 필요 | 광고 0, 오프라인 완전 동작 (PWA) |
| 누구나 쓰는 앱 | **홍지유 단 한 사람만의 앱** — 첫 화면부터 이름이 새겨진 헌정 앱 |

"자신만의 앱"이라는 프라이드는 세 겹으로 넣었습니다:
1. **첫 실행 선물 연출** — 앱을 처음 열면 "지유에게 도착한 선물" 화면이 열립니다.
2. **홈 화면 헌정문** — "이 앱은 세상에 딱 하나뿐이에요. 오직 홍지유, 너를 위해서만 만들어졌어요."
3. **편지함** — 앱스토어 어디에도 없는, 지유 이름이 불리는 편지들.

## 🎮 다섯 가지 놀이

1. **🎨 반짝 그림판** — 손가락이 지나간 자리에 빛나는 선이 만다라처럼 대칭으로 피어납니다.
   아무렇게나 그어도 화려하고 예쁜 그림이 되어 "실패"가 불가능한 그리기.
   `📸 작품 저장` 버튼으로 자기 작품을 사진으로 남길 수 있어 성취감을 줍니다.
2. **🫧 마음 방울** — "잘하고 있어", "지유 최고", "괜찮아" 같은 응원 문구를 담은
   방울이 천천히 떠오르고, 톡 누르면 별가루와 함께 포근한 종소리가 납니다.
   반복적이고 만족스러운 터치 = 손끝 진정 놀이(피젯 대용).
3. **🌬️ 숨결 별** — 4초 들이쉬고 · 2초 멈추고 · 6초 내쉬는 호흡을 별이 커졌다
   작아지며 안내합니다. 긴장될 때 스스로 마음을 가라앉히는 도구가 되고,
   한 바퀴 돌 때마다 별이 하나씩 피어납니다.
4. **🌷 지유의 정원** — 땅을 누르면 꽃이 심어지고 **영원히 남습니다** (기기에 저장).
   "정원 N일째 · 꽃 N송이"가 쌓여 매일 들어올 이유가 생기고,
   편지에 "내가 보고 싶으면 꽃을 하나 심어 줘"라고 적어 그리움을 놀이로 바꿉니다.
5. **💌 별빛 우체통** — 선물한 사람이 미리 써 둔 편지가 **하루에 한 통씩** 도착합니다.
   외국에 가서도 매일 아침 편지 한 통을 여는 것이 이모/삼촌을 기억하는 의식이 됩니다.
   인터넷이 전혀 없어도 열립니다.

소리는 어떤 순서로 울려도 어울리는 5음계 종소리만 사용하고(놀라게 하는 효과음 없음),
🔕 버튼으로 끌 수 있습니다.

## ✏️ 나만의 선물로 고치기

`index.html` 맨 위 `CONFIG` 부분만 고치면 됩니다:

- `sender` — 편지 끝에 적히는 이름 (예: `"사랑하는 이모가"`, `"삼촌이"`)
- `letters` — 편지 내용. 지유와의 실제 추억(같이 갔던 곳, 별명, 좋아하는 음식)을
  넣을수록 훨씬 특별해집니다. 편지는 몇 통이든 추가할 수 있고, 하루 한 통씩 열립니다.
- `giftMessage`, `dedication` — 첫 화면 문구

## 📱 지유 폰에 선물하는 방법

1. **GitHub Pages 켜기**: 저장소 Settings → Pages → Branch를 `main`(또는 이 브랜치)으로
   선택하고 저장하면 `https://<계정>.github.io/jiyoo/` 주소가 생깁니다.
2. 지유 폰에서 그 주소를 열고:
   - **아이폰**: 공유 버튼 → **홈 화면에 추가**
   - **안드로이드**: 메뉴(⋮) → **홈 화면에 추가** / **앱 설치**
3. 홈 화면에 "지유의 정원" 아이콘이 생기고, 이후에는 **인터넷 없이도** 열립니다.
   외국에 가서도 그대로 쓸 수 있어요.

> 정원의 꽃과 편지 진행 상황은 지유 폰 안에만 저장됩니다. 서버도, 수집되는 정보도 없습니다.

## 🛠 기술 메모

- 의존성 0개, 단일 `index.html` — 빌드 과정 없이 그대로 동작
- PWA(`manifest.webmanifest` + `sw.js`)로 오프라인·홈 화면 설치 지원
- 진행 상황은 `localStorage`에 저장 (정원, 편지 도착일, 소리 설정)
- 모든 애니메이션은 느린 속도(0.5초 이상)로만 — 빠른 점멸 없음
